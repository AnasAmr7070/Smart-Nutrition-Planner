# 🏋️ Smart Nutrition & Fitness Planner (CLI Application)

A robust Python command-line application designed to calculate daily nutritional requirements, ideal weight ranges, macronutrients, and supplement dosages.

---

## 🌟 Key Features
- **Calorie & Macro Calculator:** Uses the Mifflin-St Jeor equation for BMR/TDEE and computes target Macros based on fitness goals (Cut, Maintain, Bulk).
- **Comprehensive Food Database:** Search engine covering 20+ protein-rich foods and staples with exact nutrition values per 100g.
- **Ideal Weight Range Check:** Calculates health markers based on height and BMI formulas.
- **Supplement Guide (16+):** Provides tailored dosage recommendations for Creatine, Whey Protein, and general health supplements based on age, weight, and training status.
- **Terminal UI Styling:** Enhanced CLI interface readability using ANSI color codes.

---

## 🛠️ Built With
- **Language:** Python 3
- **Concepts Applied:** Control Flow (`if/elif/else`), User Input Handling, String Manipulation, Mathematical Calculations, Logical Operators.
